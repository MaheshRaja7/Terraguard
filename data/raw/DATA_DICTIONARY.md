This dataset is 100% SYNTHETIC, generated for the SIH26001 hackathon prototype.
It is NOT sourced from GSI, IMD, Bhuvan or any authorized government inventory.
Labels are generated from a domain-informed (but simplified) risk function, not
random assignment, so ML models trained on it learn realistic feature relationships.

| Column | Description |
|---|---|
| record_id | Unique record identifier |
| state | One of 8 NE Indian states |
| district | District within the state (subset of real district names, used for realism only) |
| latitude, longitude | Point location (decimal degrees) |
| elevation_m | Elevation above sea level (meters) |
| slope_deg | Terrain slope angle (degrees, 0-70) |
| aspect_deg | Slope compass direction (0-360 degrees) |
| soil_type | Categorical soil classification |
| land_cover | Categorical land cover/land use classification |
| distance_to_road_m | Distance to nearest road (meters) |
| distance_to_river_m | Distance to nearest river/stream (meters) |
| rainfall_1h_mm ... rainfall_7d_mm | Rainfall accumulated over 1hr/6hr/24hr/3-day/7-day windows |
| historical_landslide_count_5km | Simulated historical landslide events within ~5km radius |
| date | Record date (2015-2025) |
| landslide_probability_true | Hidden synthetic ground-truth probability (NOT a model feature - reference only) |
| landslide_occurred | Binary label (0/1) - target variable for ML |
| data_source | Always "DEMO DATA" for this dataset |

**IMPORTANT**: `landslide_probability_true` must be dropped before model training -
it is the data-generation ground truth, not an observable feature, and including
it would leak the label.
